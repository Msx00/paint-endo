## 3. 新数据流

```text
E2-L RGB + E2 depth + E2 geometry
    ↓
候选 Tv 采样与 overlap/hole/reobs 筛选
    ├─ Branch A
    │   E2 → Tv → E2
    │   → reciprocal holes
    │   → SD1.5 noise prediction L_diff_self
    │
    └─ Branch B
        E2 anchor → Tv
        neighbors → 同一 Tv
        → depth/occlusion/photometric filtering
        → robust weighted re-observation
        → timestep x0 prediction
        → L_reobs + L_known
```

推理仍为单帧：

```text
E2 → E1 pose warp → geometry mask → ReObsDiff LoRA → hard composition
```

## 4. Tensor shape

| Tensor | Shape |
|---|---|
| RGB、prediction | `[B,3,H,W]` |
| depth/mask/confidence | `[B,1,H,W]` |
| pose | `[B,4,4]` |
| SD latent | `[B,4,H/8,W/8]` |
| latent inpaint input | `[B,9,H/8,W/8]` |
| observation count | cache 中 `[H,W]`，dataset 中 `[1,H,W]` |
| source index map | `[H,W]` |

## 5. Loss

代码位于 [train_reobsdiff.py:131](</home/data/mashixing/dataset_8tb/iMed/comparison/task2/crose_endo_rendering/scripts/train_reobsdiff.py:131>)。

\[
L_{\mathrm{diff}}=
\frac{\sum (1+\lambda_mM+\lambda_bB)
\lVert\epsilon-\epsilon_\theta\rVert^2}
{\sum(1+\lambda_mM+\lambda_bB)}
\]

并应用 Min-SNR gamma=5。

\[
\hat{x}_0 =
\frac{x_t-\sqrt{1-\bar\alpha_t}\epsilon_\theta}
{\sqrt{\bar\alpha_t}}
\]

\[
L_{\mathrm{reobs,rgb}}=
\frac{\sum MC\sqrt{(I_{\mathrm{pred}}-I_{\mathrm{reobs}})^2+10^{-6}}}
{\sum MC+\epsilon}
\]

\[
L_{\mathrm{reobs}} =
L_{\mathrm{reobs,rgb}}+\lambda_{\mathrm{grad}}L_{\mathrm{Sobel}}
\]

\[
L_{\mathrm{known}} =
\operatorname{mean}_{1-M}|I_{\mathrm{pred}}-W_v|
\]

\[
L =
L_{\mathrm{diff}}+\lambda_rL_{\mathrm{reobs}}
+\lambda_kL_{\mathrm{known}}
\]

## 6. 命令

GT-depth cache 验证：

```bash
conda run --no-capture-output -n foundation_stereo \
python scripts/build_reobs_cache.py \
  --scene /path/to/session \
  --output cache/session \
  --config configs/reobsdiff.yaml \
  --set depth_source=gt \
  --resume
```

FoundationStereo 模式会严格读取预生成的 metric-depth cache，训练 epoch 内不会执行模型：

```bash
python scripts/build_reobs_cache.py \
  --scene /path/to/session \
  --output cache/session \
  --config configs/reobsdiff.yaml \
  --resume
```

训练：

```bash
conda run --no-capture-output -n foundation_stereo \
python scripts/train_reobsdiff.py \
  --cache cache/session \
  --config configs/reobsdiff.yaml \
  --output models/reobsdiff-lora \
  --steps 5000
```

推理：

```bash
python scripts/infer_reobsdiff.py \
  --input output/scene/warps \
  --output output/scene/reobsdiff \
  --lora models/reobsdiff-lora
```

泄露检查：

```bash
python scripts/audit_target_leakage.py \
  --cache cache/session \
  --training-output models/reobsdiff-lora
```

- 数据只有静态相机外参，没有逐帧位姿或 scene flow；当前 temporal provider 是 rigid V1。
- 尚未跑完整 512×640/full-dataset 训练及 E1 PSNR/SSIM/LPIPS。
- cache 中第 05 图是训练前占位诊断，不是训练后 diffusion validation prediction；固定验证集的逐 epoch 生成仍需补充。
